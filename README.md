# Customer Search Dashboard

A frontend dashboard project focused on searching and filtering customer or account information through a simple user interface.

## Features
- Customer/account search
- Account type filtering
- Balance-based filtering
- Active/inactive status filtering
- Dynamic results
- Responsive interface

## Tech Stack
- HTML5
- CSS3
- Bootstrap
- JavaScript
- DOM manipulation
- Array methods such as filter and find

## Project Type
Frontend JavaScript practice project.
